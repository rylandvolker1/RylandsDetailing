# Ryland's Mobile Detailing

Marketing website for **Ryland's Mobile Detailing** — 100% mobile auto detailing serving Horizon West &amp; Greater Orlando, FL.

## Run it locally
No build step — it's static HTML/CSS/JS.

```bash
python3 -m http.server 8000
# then open http://127.0.0.1:8000/
```

Or just open `index.html` in a browser.

## Structure
- `index.html` — the site (single page)
- `styles.css` — purple + black theme
- `script.js` — mobile nav, scroll reveal
- `assets/` — logo &amp; brand images
